# AMBER14SB Force Field Templates

MDP parameter files optimized for the AMBER14SB (ff14SB) force field.

## Key Settings for AMBER14SB

- **Cutoff scheme**: Verlet
- **vdW cutoff**: 1.0 nm
- **vdW modifier**: Potential-shift-verlet
- **Coulomb cutoff**: 1.0 nm
- **Coulomb type**: PME
- **Constraints**: h-bonds (allows 2 fs timestep)
- **LINCS order**: 4

## Reference

Maier et al., J. Chem. Theory Comput. 2015, 11, 3696-3713
